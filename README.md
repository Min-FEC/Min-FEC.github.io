# Min Qiu Academic Website

This folder contains a static GitHub Pages version of the personal academic website currently hosted at:

https://sites.google.com/view/minqiu/home

## Files

- `index.html`: home page and recent news
- `biography.html`: academic biography
- `research.html`: research interests and highlights
- `publications.html`: publication list
- `awards-grants.html`: awards and grants
- `professional-services.html`: editorships, reviewing, supervision, and teaching
- `archived-news.html`: older news entries
- `assets/css/style.css`: shared site styling

## Preview Locally

Open `index.html` in a browser.

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR_USERNAME.github.io`.
2. Upload all files in this folder to that repository.
3. In GitHub, go to `Settings` -> `Pages`.
4. Set source to `Deploy from a branch`.
5. Choose branch `main` and folder `/root`.

After GitHub finishes publishing, the site will be available at:

https://YOUR_USERNAME.github.io/

## Before Publishing

- Replace `YOUR_USERNAME` in this README with your actual GitHub username.
- Add a profile photo under `assets/images/` if desired.
- Review all copied content for typos introduced by Google Sites indexing.
- Add links to Google Scholar, ORCID, DBLP, arXiv, IEEE Xplore, or CV if desired.
